# Drift Assets

Free Lottie animations, 3D face props and 3D objects for the Drift video
editor: like & subscribe buttons, lower thirds, broadcast and meme overlays, callouts, reactions,
wearable face props and animated 3D objects.

- **Lottie** (`lottie/`): text-free vector animations with colour slots, so you can recolour them in
  Drift and add your own text with Drift's text tool. Import the `.json` into the media bin.
- **Face props** (`face-props/`): `.glb` models that track a face. `prop.json` holds the
  placement parameters for Drift's 3D face-model effect.
- **Objects** (`objects/`): animated, looping `.glb` models. Import them into the media bin.

Every asset sits in its own folder with a 512x512 `thumbnail.png` and a metadata file. See
[CONTRIBUTING.md](CONTRIBUTING.md) for the format and how to rebuild or add assets.
